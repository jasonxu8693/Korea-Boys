# Korea Boys · Seoul After Hours

Mobile trip board: itinerary, Crew Desk and Korea Pack. Extra activities are listed in Korea Pack; Activity Market is retired.

Use https://jasonxu8693.github.io/Korea-Boys/ for the full experience. Keep all static assets together; opening index.html from disk does not enable installation or the offline worker.

The existing Supabase board remains connected. Historical activity votes remain stored. Booking-option votes, notes, bookings and itinerary edits still sync. Identity, packing and last-viewed day stay on the device. Choosing a name is attribution, not authentication.

Pocket provides identity, bookings, sync refresh and an offline text snapshot. External links need internet. No push notifications or offline maps are provided.

Korea Pack includes optional Add to your phone help. After a successful online load, the static itinerary/guide/photos and last device snapshot can reopen offline. Shared edits require a connection. Updates wait until old app windows close; submit or copy session drafts and resolve unsaved changes first. Personal storage keys remain stable across updates.

Day/editor/place links retain context and named Back. Drafts remain in the current browser session until submitted or discarded. Existing saved records are preserved instead of being rewritten by historical load migrations.

Colour-analysis and Seoul–Jeju flight timings conflict between saved plan records and older reference copy. The affected days display a specific warning; use actual confirmations before travel.

Release: 2026-10-14-phone-release-1. Browser checks cover four responsive widths, preservation, return journeys, isolated failed/conflicting writes and warm offline/update behaviour. Physical iPhone/Android installation and participant usability have not been tested.
